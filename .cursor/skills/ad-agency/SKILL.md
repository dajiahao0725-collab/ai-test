# AI 광고 대행사 (Ad Agency)

7명의 서브에이전트가 협업하여 캠페인 기획서 묶음을 자동 생성한다.

## 트리거

- `/adagency`
- "광고 캠페인 만들어줘"
- "AI 광고 대행사 실행"

## 1단계: 브ief 수집

사용자에게 아래 정보를 확인한다. 이미 제공되었으면 생략 가능.

- 브랜드 또는 제품 이름
- 캠페인 목표 (인지도 / 구매 유도 / 리브랜딩 등)
- 타겟 (나이, 성별, 관심사)
- 전체 자동 실행 vs 단계별 확인

결과물 저장 폴더: `ad_campaign/`

## 2단계: AE 실행 (순차)

`ad-ae` 서브에이전트를 호출한다.

- 입력: 브랜드, 목표, 타겟
- 출력: `ad_campaign/01_ae_brief.md`
- AE 완료 전까지 다음 단계로 넘어가지 않는다.

## 3단계: 카피라이터 실행 (순차)

`ad-copywriter` 서브에이전트를 호출한다.

- 입력: `01_ae_brief.md` 전체
- 출력: `ad_campaign/02_copy.md`

## 4단계: 제작팀 4개 동시 실행

아래 4개 서브에이전트를 **한 메시지에서 병렬로** 호출한다.

| 에이전트 | 출력 파일 |
|---------|----------|
| `ad-image-team` | `03_image_ad.md` |
| `ad-video-team` | `04_video_ad.md` |
| `ad-outdoor-team` | `05_outdoor_ad.md` |
| `ad-creative-team` | `06_creative_ad.md` |

- 공통 입력: `01_ae_brief.md` + `02_copy.md`
- 각 에이전트 프로필의 `is_background: true` 설정과 함께 병렬 호출해야 한다.

## 5단계: 대표 검수 (순차)

`ad-ceo-review` 서브에이전트를 호출한다.

- 입력: `01`~`06` 전체 파일
- 출력: `ad_campaign/07_review.md`
- 대표는 `readonly: true` — 채점만 하고 산출물을 수정하지 않는다.

## 6단계: 캠페인 바이블 통합

`07_review.md`에서 **총점 50점 이상(통과)** 이면:

- `01`~`07` 내용을 하나로 통합하여 `ad_campaign/08_campaign_bible.md` 생성
- 바이블 맨 앞에 캠페인 개요(브랜드·목표·타겟·메인 카피)를 요약
- 맨 마지막 줄은 **"끝."**

**50점 미만(재작업)** 이면:

- `07_review.md`의 재작업 지시에 따라 해당 팀만 재실행
- 수정 후 5~6단계 반복

## 주의사항

- AI 크리에이티브는 **초안**이다. 클리셰·과장 표현은 사람이 최종 검수할 것.
- 핵심은 역할 분해 + 순차·병렬 워크플로우 설계다.
