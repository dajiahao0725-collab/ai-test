3. 본문

① Build 2026: Windows가 '에이전트 실행 환경'이 됩니다

6월 2~3일 샌프란시스코에서 열린 Microsoft Build 2026은 Windows를 앱만 돌리는 OS가 아니라 AI 에이전트를 등록·조율·배포하는 런타임으로 재정의하는 행사로 소개됩니다(출처 2). Windows Agent Runtime 프리뷰는 6월 Windows Insider에게 제공되며, 초기에는 JSON·XML·PDF 같은 구조화 데이터를 다루는 텍스트 에이전트부터 지원합니다(출처 2). 설치 시 파일·네트워크 접근 권한을 사용자가 승인하는 방식은 스마트폰 앱 권한 요청과 비슷합니다(출처 2).

개발자용 Microsoft Agent Framework는 Build 세션에서 프로덕션급 에이전트 구축·거버넌스·관측성을 다루는 핵심 도구로 소개됩니다(출처 1). Copilot도 여러 모델을 함께 쓰는 멀티 모델 구조로 재편된다는 점이 함께 강조됩니다(출처 2).

② 플랫폼·모델: '대화'가 아니라 '업무 위임'으로 브랜드를 바꿉니다

5월 21일 Kore.ai는 기업용 Artemis 에이전트 플랫폼을 출시했습니다. ABL(Agent Blueprint Language)과 AI 설계 도구 Arch로 멀티 에이전트를 빠르게 만들되, 배포 전 거버넌스·관측성을 넣겠다는 것이 핵심입니다(출처 3). 초기 출시는 Microsoft Azure 위에서 이루어집니다(출처 3).

Mistral은 5월 28일 Le Chat을 Vibe로 통합·리브랜딩했습니다. Work Mode는 메일·캘린더·Slack 등 연결 앱을 넘나들며 다단계 업무를 수행하고, Code Mode는 샌드박스에서 코드를 작성해 PR까지 이어갑니다(출처 4). 즉, '질문에 답하는 창'이 아니라 일을 맡기는 직원에 가깝게 포지셔닝합니다(출처 4).

모델 측면에서는 Google Gemini 3.5 Flash가 에이전트·코딩에 최적화된 3.5 패밀리의 첫 모델로 공개되었고(출처 5), 개인용 에이전트 Gemini Spark에도 적용됩니다(출처 5). OpenAI GPT-5.5는 4월 출시 이후 ChatGPT·Codex에서 도구를 연결해 실무를 끝까지 처리하는 방향을 강조합니다(출처 6). 6월 1일 기준 Gemini Enterprise는 3.5 Flash를 GA로 제공하며, Agent Designer 기본 모델도 3.5 Flash로 이전되었습니다(출처 7).

③ 거버넌스: 에이전트가 많아질수록 '안전 장치'가 경쟁력이 됩니다

에이전트가 24시간 돌아가면 데이터 유출·무단 행동 위험이 커집니다. NVIDIA NemoClaw는 OpenClaw 기반 에이전트에 OpenShell 샌드박스·네트워크·프라이버시 정책을 더한 참조 스택입니다(출처 8). Dark Reading은 기업이 에이전트 행동 가시성과 정책 집행을 가장 큰 과제로 보며, NemoClaw가 확률적 안전이 아닌 인프라 수준의 통제를 지향한다고 정리합니다(출처 9).

4. 소결론

이번 주 AI 핫 트렌드는 ① OS·클라우드가 에이전트 인프라로 재편(Build 2026), ② 플랫폼·모델의 '업무 위임' 경쟁(Artemis·Vibe·Gemini 3.5·GPT-5.5), ③ 거버넌스가 도입 조건(NemoClaw 등) 세 축으로 요약됩니다. 트렌드 목록을 쫓기보다, 범위가 좁고 결과를 측정할 수 있는 업무 하나를 정해 에이전트를 시험하는 접근이 현실적입니다.

작성자 노트
