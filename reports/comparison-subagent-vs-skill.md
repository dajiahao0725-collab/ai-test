# report-writer 서브에이전트 vs 스킬 직접 적용 — 결과 비교

> 작성일: 2026-06-02  
> 비교 대상: `ai-hot-trends-2026-06-02-subagent.md` vs `ai-hot-trends-2026-06-02-skill.md`

## 요약 한 줄

**같은 report-writer 규칙·같은 주제**였지만, **서브에이전트는 '모델·규제·글로벌 거시'**, **스킬 직접 적용은 'Build 인프라·개발·배포'**에 무게를 두어 **초점·출처·분량·구조**에서 차이가 났습니다.

---

## 1. 핵심 주장 비교

| 구분 | 서브에이전트 (1번) | 스킬 직접 적용 (2번) |
|------|-------------------|---------------------|
| **한 줄 요약** | Build + 모델 출시 + EU 규제가 겹친 **전환점** | Windows를 **에이전트 OS**로 재정의한 **인프라 전쟁** |
| **강조 축** | MAI·Polaris + Opus 4.8·M3·Cosmos 3 + EU AI Act | Agent Runtime·Store·Mesh + Agent Framework + Vibe·Artemis |
| **시각** | 업계 전반(기술·규제·시장) | 개발자·플랫폼 관점 |

---

## 2. 출처·근거 차이

| 항목 | 서브에이전트 | 스킬 직접 적용 |
|------|-------------|---------------|
| **출처 수** | 10건 | 7건 |
| **공식 1차 자료** | Anthropic, NVIDIA, MiniMax, Microsoft DevBlog, EU 기관 | GitHub, Mistral, Kore.ai + Build 리캡 블로그 |
| **규제·시장** | EU AI Act, Gartner Hype Cycle 포함 | 미포함 (작성자 노트에 범위 축소 명시) |
| **Build 상세** | MAI 모델·Polaris 중심 | wagent CLI, Agent Store, Azure Agent Mesh, Adobe·Zoom 파트너 |
| **모델 트렌드** | Opus 4.8, MiniMax M3, Cosmos 3 상세 | Polaris + Vibe·Artemis만 간략 언급 |

**해석:** 서브에이전트는 **독립 웹 검색**으로 최근 모델·규제 이슈를 넓게 수집했고, 스킬 직접 적용은 **Build 2026 인프라 스택**에 출처를 집중했습니다.

|------|-------------|---------------|

## 4. 형식·스킬 준수 차이

| 항목 | 서브에이전트 | 스킬 직접 적용 |
|------|-------------|---------------|
| **경어체** | ✅ 일관 | ✅ 일관 |
| **출처 표기 (출처 N)** | ✅ | ✅ |
| **작성자 노트** | ✅ (Build 키노트 재확인 권고) | ✅ (스킬 직접 적용·범위 축소 명시) |
| **마지막 줄 "끝."** | ✅ | ✅ |

스킬 필수 항목(핵심 주장·출처·본문·소결론·작성자 노트·끝.)은 **둘 다 충족**했습니다.

---

## 5. 왜 차이가 나는가

| 원인 | 설명 |
|------|------|
| **실행 주체** | 서브에이전트 = 별도 프로세스·독립 검색 / 스킬 = 현재 대화 맥락·선택적 검색 |
| **검색 결과 편차** | 같은 날짜라도 검색 쿼리·순위에 따라 EU·MiniMax vs Agent Store·Mesh 등 다른 이슈가 부각 |
| **맥락 공유** | 스킬 직접 적용은 이전 대화에서 Build·Vibe·Artemis를 다룬 기록이 있어 **플랫폼 인프라** 쪽으로 수렴 |
| **범위 판단** | 서브에이전트는 "이번 주"를 **모델+규제+Build**로 넓게 해석 / 스킬 쪽은 Build·배포 생태계에 **의도적 집중** |

비유하자면, **같은 레시피(report-writer 스킬)로 요리**했지만  
- **서브에이전트** = 재료 창고를 넓게 뒤져 **종합 코스**를 낸 셰프  
- **스킬 직접 적용** = 이미 손에 든 Build 재료로 **메인 요리 한 접시**에 집중한 셰프  

---

## 6. 실무적 선택 가이드

| 목적 | 추천 |
|------|------|
| 팀플·경영 보고 (거시·규제·시장) | **서브에이전트** 결과가 유리 |
| 개발·IT 기획 (Build·SDK·배포) | **스킬 직접 적용** 결과가 유리 |
| 최종 제출용 | **두 초안 병합** — Build 인프라(2번) + 모델·EU(1번) |

---

## 7. 결론

1번과 2번은 **형식(스킬 규칙)은 동일**하지만, **내용의 초점·출처·깊이**에서 뚜렷이 달랐습니다.  
서브에이전트는 **독립 조사·넓은 시야**, 스킬 직접 적용은 **대화 맥락·주제 집중**이 차이를 만든 핵심 요인입니다.

끝.
